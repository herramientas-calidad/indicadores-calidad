# Indicadores

Aplicación web: **https://herramientas-calidad.github.io/indicadores-calidad/** (versión 2026.13).

Aplicación web (PWA) estática, sin dependencias, que funciona sin conexión y se puede instalar en el móvil, para crear, definir y comprobar indicadores de calidad y seguridad del paciente, paso a paso, como en el curso «Auditorías para la Mejora de la Seguridad del Paciente. Del Mapa de Riesgos a la Mejora Continua».

Asistente en seis pasos: del hallazgo del Mapa de Riesgos al indicador, caracterización (tipo y forma de cálculo), definición operativa, comprobación de su calidad (SMART, válido, fiable, útil, con pilotaje), muestra (con la calculadora Tamaño Muestral, que va incluida en la carpeta `tamano-muestral/`) y ficha imprimible. Además: indicador compuesto con su desglose, cuadro de indicadores exportable a Excel, copia de seguridad e importación, enlace para compartir un indicador, «Aprende», glosario y «Ponte a prueba». Los datos se guardan solo en el dispositivo.

Forma parte de un conjunto de herramientas de calidad y seguridad del paciente. Si quieres conocer las demás, pide información a sus autores.
